## 🎯 TL;DR - The Absolute Minimum

```javascript
// 1. Import
import axios from 'axios';

// 2. Call endpoint
const response = await axios.post(
  '/api/v1/menu/render-pdf',
  {
    title: 'Menu',
    items: [{ name: 'Item', price: 100 }]
  },
  { responseType: 'blob' }  // ← CRITICAL!
);

// 3. Download
const url = URL.createObjectURL(response.data);
const link = document.createElement('a');
link.href = url;
link.download = 'menu.pdf';
link.click();

// Done! ✅
```

## 💡 Pro Tips

1. **Always set `responseType: 'blob'`** - Most common mistake
2. **Test with minimal payload first** - Before complex menus
3. **Use setTimeout for print dialogs** - Gives time for PDF to load
4. **Cache PDFs if identical** - Avoid regenerating same menu
5. **Compress images** - Reduces PDF file size
6. **Use HTTPS URLs** - For images in production
